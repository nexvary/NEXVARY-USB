# NEXVARY USB Studio v0.8.3 — إصلاح فحص EF_DIR

## الأدلة

في صور Huawei K3770، نجح CSIM كاختبار صيغة، ونجح SELECT MF بنتيجة SW=9000. انتهت مهلة CGLA، ومنعت الجلسة غير المكتملة متابعة CCHO وCRSM. تعذّر تحديد طول سجلات EF_DIR. هذه النتائج لا تثبت غياب USIM أو نجاح AKA.

## الإصلاح

- عندما يرد GET RESPONSE لملف EF_DIR بطول P3=0 بنجاح دون بيانات، يُرسل طلب قراءة وصف آخر بطول 15 بايت مرة واحدة فقط؛ لا إعادة عند المهلة أو الرفض أو رد ناقص.
- أي رد فارغ آخر يبقى UNKNOWN، ولا يُفترض غياب USIM أو ISIM.
- قبول قيمة CRSM الست عشرية بنص مقتبس أو غير مقتبس مع التحقق من الصيغة.
- ترتيب الفحص: CRSM قبل CGLA وCCHO لتجنب حجب نتائجه بسبب المهلات المعروفة، دون إلغاء قاعدة توقف الجلسة غير المكتملة.
- اختبارات اصطناعية للاستجابة الفارغة والمهلة والترميز وترتيب الأوامر.

## ما لم يثبت

لم يحدث اختبار أجهزة جديد في CI. لا إثبات لقراءة EF_DIR الحقيقية أو الوصول إلى USIM AID أو مصادقة AKA أو IMS أو ePDG أو إجراء المكالمات. لم تُرسل PIN/PUK، ولم يُعدل Firmware أو ملفات الشريحة.

## مراجع

ETSI TS 102 221 يصف EF_DIR من نوع linear-fixed وبيانات وصف الملف، وETSI GSM 11.11 يصف بيانات GET RESPONSE ذات الرأس 15 بايت.
