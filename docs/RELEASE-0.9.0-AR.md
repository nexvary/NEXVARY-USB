# NEXVARY USB Studio v0.9.0 — صفحة نتائج مستقلة

## سبب التعديل
في صور اختبار Huawei K3770 كان المستخدم مضطرًا إلى التقاط نصف جدول النتائج، ثم التمرير والتقاط نصفه الثاني. لم تكن المشكلة في الفلاشة ولا في طريقة التصوير؛ تصميم الشاشة وضع الأزرار والجدول في صفحة واحدة ولم يوفر تصدير صورة كاملة.

## التنفيذ
- صفحة «النتائج» مستقلة بعرض النافذة بالكامل مع زر رجوع لمعلومات الشريحة.
- انتقال تلقائي بعد انتهاء الفحص الشامل واختبار EF-ICCID وSELECT MF وتطبيقات SIM/USIM، باستثناء مساعد الخطوات الذي يحافظ على تسلسله.
- جدول مختصر: الفحص، الحالة، التفسير؛ تفاصيل الحالة في التلميحات.
- زر «حفظ صورة كاملة PNG»: ينشئ صورة واحدة تشمل كل صف حتى عند تجاوز طول التقرير ارتفاع الشاشة، دون تمرير أو تجميع لقطات.
- تمييز واضح للتقارير الاصطناعية وتنقيح المعرّفات عند التصدير.
- بقاء تقارير JSON/CSV ومسارات الأجهزة والشبكة كما هي.

## التحقق
اختبارات UI فعلية على Windows وUbuntu بمقاسات متعددة ونسب DPI 100%/125%/150%. تُؤكَّد نتيجة بناء المثبّت من GitHub Actions، لا من هذا المستند.
لا يثبت هذا الإصدار مصادقة USIM AKA أو مكالمات VoWiFi.
