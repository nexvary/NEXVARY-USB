# NEXVARY USB Studio v0.9.1

تعالج هذه النسخة التقرير الميداني الذي أظهر نجاح AT وCPIN وCSIM وCRSM وقراءة ICCID، بينما ظهرت «Truncated SIM TLV» في «تطبيقات الشريحة».

- صار تفسير الأخطاء يميز بين TLV مبتور في وصف EF_DIR وتلف صيغة سجل EF_DIR محدد، بدل إظهار استثناء إنجليزي خام.
- تدعم القراءة حشو FF و00 فقط إذا كان متجانسًا في نهاية السجل، ولا يتم قبول TLV غير مكتمل أو تخمين طوله.
- لا يثبت أي رفض أو تلف TLV عدم وجود تطبيق USIM؛ حالة الاكتشاف غير محسومة.
- النتائج والتصدير المصور يتضمنان وصفًا عربيًا مقتضبًا، ولا يعيدان طباعة ملاحظات AT الإنجليزية أو استجابات الموقع الخام.
- تُحذف LAC وCell ID من استجابة +CREG قبل إنشاء التقرير، وليس من الصورة فقط؛ تُنقح الصور القديمة أيضًا عند إعادة تصديرها.
- أضيفت اختبارات اصطناعية لهذه الحالات وتحقق على Windows وUbuntu عبر GitHub Actions.

لم نختبر هذا التعديل على فلاشة فعلية؛ النجاح في المحاكاة لا يثبت وصول تطبيق USIM أو AKA أو VoWiFi.
