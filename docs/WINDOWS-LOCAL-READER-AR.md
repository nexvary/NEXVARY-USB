# تجربة قارئ Windows بتوقيع محلي

هذه حزمة تطوير UMDF x64. ليست شهادة تجارية أو توقيع Microsoft، ولا إثباتًا للتوافق مع جهازك أو شريحتك. الشهادة ذاتية ومحدودة بثلاثة أشهر؛ مفتاح التوقيع غير قابل للتصدير ويحذف من آلة البناء بعد التوقيع. الحزمة تحتوي الشهادة العامة فقط.

استخرج الحزمة في مجلد واحد ثم انقر `Local-Reader-Setup.cmd`. اقبل طلب مسؤول Windows ثم اقرأ نافذة الموافقة العربية وبصمة الشهادة. قد تمنع سياسة PowerShell أو سياسة مؤسسة تشغيل الأداة؛ لا تغيّرها الأداة تلقائيًا.

الموافقة تضيف شهادة المشروع إلى Root وTrustedPublisher على هذا الكمبيوتر. هذه ثقة محلية جديدة في ناشر الحزمة وليست اعتمادًا عامًا. الأداة تتحقق من البصمات وتوقيع DLL وCAT ثم يستمر المثبّت في التحقق الأصلي من سلامة INF/DLL داخل CAT. لا تعطيل لتوقيع التعريفات أو Secure Boot، ولا TESTSIGNING ولا استبدال لتعريفات أخرى. إذا فشلت التجربة تُزال الشهادات التي أضافتها هذه المحاولة فقط، ويحاول المثبّت إزالة جهازه الجديد إذا فشل تثبيته.

التقرير `NEXVARY-Local-Reader-Report.json` على سطح المكتب يفصل قبول التوقيع والتثبيت وتعداد PC/SC. نجاح التثبيت لا يثبت الاتصال بالشريحة أو نقل APDU. بعد ظهور القارئ، شغّل قارئ SIM الافتراضي داخل USB Studio بموافقة جديدة ثم نفّذ التشخيص الميداني؛ لا ترسل AUTH عبر المسار المحلي المخصص للقراءة فقط.

لإلغاء الثقة بعد تجربة ناجحة: افتح إدارة شهادات الكمبيوتر `certlm.msc` واحذف من Root وTrustedPublisher الشهادة ذات البصمة المطابقة للتقرير فقط. لا تحذف شهادات أخرى. لا يُزال التعريف المثبت بمجرد إزالة الشهادة. صلاحية التوقيع المحلي وحدها لا تضمن قبول سياسات Windows المختلفة أو تشغيل UMDF1.
