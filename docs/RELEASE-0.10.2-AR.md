# USB Studio 0.10.2 — دليل USIM الميداني وعميل PC/SC مستقل

## الدليل الجديد

صورة المالك NEXVARY-esults.png بتاريخ 2026-10-10، من الإصدار 0.10.1، تثبت في التقرير K3770 / 21.023.04.00.11 وSIM READY وMF 9000 وقراءة EF_DIR بخمسة سجلات طول كل منها 33 بايتًا واكتشاف AID واختيار USIM. هذا دليل ميداني قدمه المالك، وليس محاكاة أو إعادة اختبار مستقلة. يُحفظ SHA256 في ملف التوافق؛ JSON التفصيلي لم يصل. VID/PID غير متاح في الصورة الجديدة، ويبقى 12D1:14C9 دليلًا سابقًا فقط. لم تثبت ISIM أو AKA أو PC/SC خارجي أو ePDG أو IMS أو المكالمات.

## الاختبار الخارجي من Windows

«قارئ SIM الافتراضي» ← «اختبار PC/SC بعميل مستقل». ينشئ التطبيق عملية مستقلة تستخدم WinSCard مباشرة، ويوقفها بعد 30 ثانية دون إعادة APDU. لا تحتاج تثبيت Python عند استخدام EXE. تظهر النتائج في صفحة النتائج ويمكن حفظها PNG أو JSON/CSV بالطريقة المعتادة. يحتاج الاختبار قارئ NEXVARY واحدًا مثبتًا، وخدمة القارئ بموافقة سارية. عند غياب التعريف يظهر عدم توفر القارئ؛ لا نجاح مفترض من حالة الخدمة. لا يختار قارئًا آخر تلقائيًا. عند تعدد القارئات يستخدم المطور خيار --reader بالاسم الصريح.

من المصدر على Linux أو Windows:

```bash
python -m nexvary_usim_lab pcsc-check --consent --export field-pcsc.json
```

يبقى scripts/check_field_pcsc.py صالحًا للعميل المستقل وCI. لا AUTH أو PIN أو كتابة ملفات أو تثبيت تعريف أو تغيير pcscd/SCardSvr. ATR الافتراضي وإعادة اختيار الجلسة ليست ATR ماديًا أو reset كهربائيًا. التقرير الخارجي لا يحدد وحده هل بطاقة الخدمة اصطناعية أو فعلية؛ يلزم ربطه بتقرير المضيف.

## Windows والتسليم

تعريف Windows ما زال مصدرًا خارجيًا معزولًا يحتاج WDK مناسبًا وبناءً وتوقيعًا واختبارًا منفصلًا. الإصدار لا يتضمن تعريفًا مثبتًا أو موقّعًا، ولا يعطّل حماية Windows. Direct CSIM الذي نجح ميدانيًا متاح دون التعريف. نجاح البناء/CI مع بطاقات اصطناعية لا يثبت الأجهزة أو حقوق المشغل. لم تتغير شفرة Android أو الخادم المنشور، ولم تُنفّذ مصادقة على شريحة المستخدم.
