# أداة NEXVARY لإصلاح تعريف المودم — 1.0

أداة مستقلة مضافة إلى مستودع USB Studio؛ لا تحتاج تثبيت نسخة جديدة من البرنامج.
فك ضغط الحزمة، ثم اضغط يمينًا على **Start-Recovery.cmd** واختر **Run as administrator**.
أغلق NEXVARY وVodafone ثم اضغط Enter. تعرض الأداة ثلاث مراحل:

1. قراءة أجهزة Huawei الحالية وأكواد أخطاء Windows.
2. تصدير حزم تعريف المودم المرتبطة به، ونسخ ملفات قرص Huawei/Vodafone الافتراضي مع مقارنة SHA-256 لكل ملف.
3. البحث محليًا عن ملفات INF المطابقة لمعرّفات الواجهات الفعلية، والتحقق من توقيع CAT، ثم طلب كتابة **REPAIR** قبل تثبيتها بواسطة PnPUtil. Windows يتحقق من عضوية الملفات في الكتالوج ومن ملاءمة التعريف؛ لا تجبر الأداة تعريفًا أقل ترتيبًا.

تُحفظ النتائج في Documents داخل مجلد يبدأ بـ NEXVARY-Recovery. أرسل before.json وafter.json عند وجودهما؛ لا ترسل مجلد النسخ كله لأنه يحتوي ملفات الشركة.
الأداة تتعامل مع Huawei VID 12D1 فقط. لا تثبت تعريفات أجهزة الكمبيوتر الأخرى، لكن حزمة Huawei نفسها قد تطبق على مودم آخر متصل يطابقها؛ افصل المودمات الإضافية قبل الإصلاح.
إذا لم تجد تعريفًا مطابقًا موثوقًا، تتوقف وتطلب مجلد تعريف رسمي محلي. نسخ حزمة معطوبة وإعادة تسجيلها لا يضمن إصلاح Code 31؛ قد تحتاج حزمة رسمية متوافقة مع Windows 10. لا تتجاوز الأداة التوقيع ولا تحمل تعريفات عشوائية ولا تحذف حزمًا ولا تعدل Registry.

**النسخة الاحتياطية للقرص الافتراضي ليست نسخة Firmware داخلي ولا نسخة شريحة SIM.** لا ترسل الأداة أي AT/APDU ولا تعدل Firmware أو إعدادات USB الدائمة ولا تفك قفل الاشتراك.
إذا انتهت أوامر التعريفات دون ظهور منافذ مودم، لا تعلن نجاحًا. ظهور المنافذ بدون خطأ لا يثبت AT أو SIM أو AKA؛ يفحصها USB Studio منفصلة.
الـ CMD يستخدم ExecutionPolicy Bypass لعملية PowerShell الحالية فقط؛ لا يغيّر سياسة الجهاز ولا يعطل فحص توقيع التعريفات. الشفرة مفتوحة للمراجعة، ولا توجد تنزيلات شبكية.

الاختبارات البرمجية تحاكي أجهزة وأوامر Windows؛ ليست تجربة على K3770 فعلية. الصورتان المرسلتان تثبتان Code 31 ثم أربع واجهات غير معرّفة، ولا تثبتان تلف Firmware.
